الحالة بتاريخ 2026-10-12. كل بند له: **من ينفّذه**، و**كيف تتحقق**. لا تفتح `ALLOW_SIGNUP` للجمهور قبل إغلاق بنود «حاجز» (🛑).

> الرموز: ✅ تم وتحقّقنا · 🟡 تم جزئيًا · ⬜ لم يتم · 🛑 حاجز للإطلاق

## 0) قرار البنية (اقرأه أولًا)

السيرفر الحالي **WSL على جهاز Windows منزلي/مكتبي** ويظهر للإنترنت عبر Tailscale Funnel. مناسب للتجربة وأول عملاء، **لكنه نقطة فشل واحدة**: انقطاع كهرباء أو تحديث Windows أو نوم الجهاز = توقف الخدمة لكل الشركات.

| الخيار | متى |
|---|---|
| إبقاء الوضع الحالي | عدد محدود من العملاء المعروفين، وتقبل توقفًا عرضيًا |
| **VPS صغير (2 vCPU / 4 GB)** | قبل أي عميل يدفع ويعتمد على النظام يوميًا (موصى به) |

الانتقال لـ VPS: نفس `docker compose` + استعادة آخر نسخة (`docs/BACKUP-RESTORE.md`) + تغيير `PUBLIC_BASE_URL` والـ webhook.

## 7) اختبار الإطلاق النهائي (يوم الإطلاق)

نفّذ بالترتيب بحساب جديد تمامًا:

1. افتح `ALLOW_SIGNUP=true` وسجّل شركة بإيميل حقيقي.
2. أضف صنفًا وعميلًا وأنشئ فاتورة بيع وطباعتها، وراجع الداشبورد.
3. ادفع باقة بمفتاح `live` بمبلغ حقيقي واسترده بعد التأكد.
4. تأكد أن الاشتراك تفعّل وظهرت الدفعة في لوحة المنصة.
5. من لوحة المنصة: أوقف الشركة وتأكد أن الدخول مرفوض، ثم أعد تفعيلها.
6. من جهاز آخر وشبكة مختلفة (جوال بيانات) افتح الرابط العام وتأكد من السرعة.
7. شغّل سحب النسخ يدويًا وتأكد أن الشركة الجديدة داخل آخر نسخة.
8. أعد تشغيل جهاز السيرفر وتأكد أن الخدمة عادت وحدها.

## أوامر التحقق على السيرفر

```bash
# 1.2 عزل قاعدة البيانات — المتوقع: 64|49|f
cd /opt/alfannan && docker compose --env-file .env.docker -p alfannan exec -T db psql -U postgres -d alfannan -tAc "select (select count(*) from pg_class where relrowsecurity and relforcerowsecurity and relkind='r'), (select count(*) from pg_trigger where tgname='app_tenant_refs'), (select rolsuper or rolbypassrls from pg_roles where rolname='alfannan_app')"

# 1.7 صلاحيات الأسرار
chmod 600 /opt/alfannan/.env.docker && ls -l /opt/alfannan/.env.docker*

# 3.8 الفرض والدفع داخل الحاوية (بدون كشف المفاتيح)
docker compose --env-file .env.docker -p alfannan exec -T api sh -c 'echo "ENFORCE=$SUBSCRIPTION_ENFORCEMENT PAY=$PAYMENTS_ENABLED KEY=$(echo $MOYASAR_SECRET_KEY | cut -c1-8)"'

# 5.4 المساحة
df -h /opt/alfannan; du -sh /opt/alfannan/backups
```
